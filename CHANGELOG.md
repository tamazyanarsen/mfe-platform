# Changelog

## 0.1.0

Первый публичный релиз пакетов `@mfe-platform/*`.

- Контракт ремоута: манифест, идемпотентная `register()`, навигация через хост, шина и стор.
- `<mfe-outlet>`: загрузка по маршруту, предзагрузка по наведению, fallback с повтором,
  события наблюдаемости.
- Несколько версий UI-кита на странице: постфиксы тегов по линии совместимости, учёт и
  политики; один экземпляр кита для ремоутов одной линии.
- Целостность кода ремоутов: цепочка хешей от конфигурации хоста до каждого чанка.
- Права ремоутов на поля общего стора.
- Хост под префиксом пути; production-сборка ремоута с `publicPath: "auto"`.
- Инструменты: `create:remote`, `@mfe-platform/testing`, `@mfe-platform/devtools`,
  подмена ремоута, бюджет размера.
