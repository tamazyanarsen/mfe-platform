# probe

Тестовый ремоут, не часть демо: второй ремоут на `@rwcjs/ui` 0.1 рядом с payments. На нём
e2e проверяет, что ремоуты одной линии кита делят один его экземпляр, а не конфликтуют.

В конфигурации хоста его нет: тесты подключают его подменой
`?mfe-override=probe=http://localhost:3004/mf-manifest.json`.
